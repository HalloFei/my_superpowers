# 术语纪律（Term Discipline）

## 0. 唯一判据

**读者不需要停下来猜一个词，也不需要猜两次。**

判定方法：把首次出现的术语交给不在上下文里的读者，他必须能回答两件事 —— ① 它指什么；② 拿到一个新例子，怎么判定它算不算这个词。答不出任一项，就是缺定义。

> 低负荷不等于幼稚化：目标是**澄清**，不是删掉术语。术语该用就用，但必须先付定义的成本。

## 1. 何时用

- 写/改文档、报告、设计、复盘、说明的正文
- 回答里出现缩写、代号、单字母符号、自造词
- 审阅文本时看到「大家都懂」的词
- 不适用于：代码标识符、报错原文、命令、路径、API 名（一律保持原样）

## 2. 六条硬规则

### T1 自造/多义术语：三件套，缺一不用

首次出现必须同时给 **定义 / 判定方法 / 锚点**；缺任何一件就不许用这个词，改用具体描述。

- 定义：一句话说清它指什么
- 判定方法：别人拿这个定义，对任意新情况能给出**同样的答案**（可操作，不是仅描述）
- 锚点：`file:line` / 配置项 / 规范节 / 数据字段

反例：用「数据驱动 / 代码驱动」描述改动成本 —— 未定义且是错误二分法。改为三档并给判定式：「加这个取值需要修改 `.py` 源文件吗？」

### T2 缩写：首现展开，之后不改口

- 首次出现：`中文名（English Full Form, ABBR）`，例：`检索增强生成（Retrieval-Augmented Generation, RAG）`
- 之后正文用同一形式；不要一会儿全称、一会儿缩写、一会儿中文译名
- **只出现一次的缩写不引入**，直接写全称
- **标题、小节标题、首段、表头、图注都算「首次出现」**：标题里必须写全称，或使用读者已知的项目名；不允许在标题里首次引入缩写
- 判断标准是**读者停顿测试**：读者需要停一下才能解码 → 展开或换词，而不是「它是不是英文缩写」

### T3 全称优先，符号只进公式与表格

- 正文写中文名/全称；符号（`n`、`N`、`W`、`S_t`、`α`、`⇒`）只出现在公式、表格、图注
- 单字母必须先在记号表里定义过，才允许在正文使用
- 不用单个字符或箭头代替概念：写「上升/下降」不写「↑/↓」；「因此」能写成词就写成词

### T4 记号表先于符号

长文/报告在正文第一次使用符号前，给一张全文统一的记号表：

| 符号 | 中文名 | 定义 / 公式 | 单位 | 不许叫成 |
|---|---|---|---|---|
| SE | 标准误 | 估计值自身的波动 | 同点估计 | 「误差」「标准差」 |

一个符号只许一个含义；一个概念只许一个符号。

### T5 同词异义：写消歧块

本文的 X 与另一份文档的 Y 不是一回事时，在首次定义处显式写：

> ⚠️ **词汇消歧（必须遵守）**：本文的 `layer` = 哈希域 / 互斥组；与某文档的「三层 A/B 模型」（管道层）**不是一回事**。

### T6 长文术语表 + 自造代号登记

- 长报告给「术语（本报告口径）」表：`术语 | 含义（本报告口径） | 判定方法 | 锚点`
- 自造代号（T1/F2/A14 之类）集中登记；引用时必须带定义或展开，不能裸用

## 3. 中文 + 英文政策

- 正文中文；术语、方法名、指标、论文原名保留英文，不硬造中文译名替代
- **一个概念只用一个词**，禁止同义词轮换（「直接偏好优化 / DPO / DPO 算法」只能留一个）
- **中文名与英文名混用也算两种叫法**：选定正文主形式（如统一用「13 type」或统一用「13 型」），另一种只在首次括注或术语表出现
- 中文标点用全角；句末用中文句号；英文术语保留原大小写（`MDE` 不写 `mde`）

## 4. 模板

### 术语表（可直接嵌进文档）

```markdown
## 术语与记号（本文口径）

> 本表定义**本文**用法；与其它文档同名不同义处，见「消歧」列。

| 术语 / 记号 | 全称 | 含义（本文口径） | 判定方法（怎么算 / 怎么判） | 锚点 |
|---|---|---|---|---|
| MDE | Minimum Detectable Effect | 样本量能分辨出的效应下限 | 给定 α、1−β、σ、n 后按公式解出的 δ | docs/knowledge/... §3 |
```

### 首现句式

- 缩写：`最小可检测效应（Minimum Detectable Effect, MDE）`
- 定义：`MDE 是……`（一句话，≤30 字为佳）
- 自造词：`T1（= 在既有分支点插入「读 tag → 有则用、无则回落」）`

## 5. 交付前自查

### 5.1 术语扫描（机械步骤，先做这一步）

1. 扫出全文所有：**2 个及以上大写字母的缩写**、**单字母符号**、**引号包裹的自造词**、**首字母大写的专名**
2. 对每一个，找到它在全文中的**第一次出现**
3. 该位置必须能指向：全称展开 / 记号表条目 / 三件套定义。指不到 → 补定义，或把标题/首段里的它改成全称
4. 同一个词的后续写法与第一次一致

### 5.2 自查清单

- [ ] 每个缩写首现都有全称
- [ ] 每个单字母符号都在记号表里
- [ ] 每个自造词都有三件套，否则已展开成描述
- [ ] 同一概念没有第二种叫法
- [ ] 正文没有裸符号、裸箭头、单字指代
- [ ] 长文有术语表，表头写明「本文口径」
- [ ] 英文术语没有被强行翻译成两个名字

## 6. 常见错误

| 错法 | 后果 | 改法 |
|---|---|---|
| 「大家都懂」的缩写直接用 | 跨团队读者被迫猜 | 首现展开；只出现一次就写全称 |
| 同一概念三种叫法 | 检索与引用失效 | 定一个词，全文统一 |
| 用 `n` 指三个不同的量 | 数字无法复核 | 记号表；一个符号一个含义 |
| 在标题里首次引入缩写 | 标题不可搜、不可读 | 标题用全称 |
| 自造词不定义 | 讨论在无共同判定下推进 | 三件套，否则改用描述 |
