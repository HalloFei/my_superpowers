# 证据纪律（evidence）

本文件是 `writing-docs` 与 `scientific-writing` 共用的证据规则。任何一条实质断言，都要能被第三者在 5 分钟内复核。

## 1. 断言级：二选一

| 标签 | 必要条件（缺一不可） |
|---|---|
| `[代码事实]` | ① 带 `<repo>@<rev>:<path>:<line>`；② 确实在该修订上读过（不凭文档 / 注释 / 其它分支 / 记忆）；③ 关键结论不能只靠一次 grep，须换方式交叉验证 |
| `[提案]` | 只写「我建议 / 我的判断是」；禁止写成 "the helper is" / "the design is" 这类既成事实语气 |

**混写视为缺陷。** 把提案写成事实，会让下游据此排期 / 发版。

## 2. 文档级：五档

| 标签 | 含义 | 读者能期待什么 |
|---|---|---|
| `[实测 YYYY-MM-DD]` | 本轮现场跑过，输出内联 | 命令、输出、日期 |
| `[转引 YYYY-MM-DD]` | 仓内已有实测，本轮未复跑 | 原始日期与出处；**不声称今天仍成立** |
| `[设计]` | 由已冻结的 ADR / spec 决定 | 决策来源 |
| `[假设]` | 人为假设（如 p = 1） | 明确标注「不是实测」；给风险与重开条件 |
| `[未验证]` | 不知道且没有证据 | 明确写「不知道」，不给估计值 |

## 3. 环境级：E0–E3（工程仓）

| 等级 | 定义 | 文档里允许的措辞 |
|---|---|---|
| `E0` | 任何人靠 git + 文本即可复核 | 「事实」「见 file:line」「已核对」 |
| `E1` | 本机解释器可跑出确定性结果 | 「实测」「本机实测 N passed」 |
| `E2` | 需 GPU / 模型 / 专用环境 | `UNVERIFIED(E2)` + 待跑命令 + 判据 |
| `E3` | 需下游 / 线上 | `UNVERIFIED(E3)` + 触发条件 |

**规则**：E2/E3 的断言不得出现在「验收 / 已验证 / ✅」后面，只能出现在「待验证」节并附 `blocked_by`。

## 4. 锚点格式

| 场景 | 格式 | 例 |
|---|---|---|
| 跨仓 | `<repo>@<rev>:<path>:<line>` | `ai-soulmate-flow@63ca8ee5c:.../IntentClassifyNodeHandler.java:364` |
| 仓内 | 按符号 / 文句定位；行号必须带基线日期 | `AGENTS.md §7（2026-11-06）` |
| 实验数据 | 命令 + 输出摘要 + 日期 | `pytest -q → 23 passed (2026-11-06)` |

只写 `file:line` 而不写是哪个仓、哪个修订，等于没有引用。行号会漂移，跨修订引用必须带 rev。

## 5. 四元组：主张 / 证据 / 支撑范围 / 越界即错

关键结论必须一行四列。只写前两列不合格——**合法但错误的外推**（= 越界）是最常见的证据事故。

## 6. 不编造

- 不编造作者、机构、链接、数字、引用数、日期、审批
- 缺失信息写「未给出」或留空；留空是可被补全的状态，编造是不可恢复的污染
- `[假设]` 不得写进代码 / 配置当默认值；一旦真实值不符，触发重开
- 检索摘要、模型记忆、他人参考文献 = 线索，不是证据

## 7. 「0 命中」不是「不存在」

任何「不存在」的结论，据此断言前必须换一种方式复核（直接读文件 / 换 pattern / 查 tree object），并记录工装陷阱（如引号被吞、正则 ERE 语义）。

## 8. 证据索引

长文 / 知识文档末尾给「断言 → 位置」表：

```markdown
## 附录：证据索引

| 断言 | 位置 |
|---|---|
| 分桶确定性 | `docs/knowledge/...md` §2；`tests/split/test_...py:41` |
```

## 9. 版本不产生新证据

报告的证据在 meta 的 `sections[].evidence` 里声明一次，所有渲染版本引用同一条；版本只换选块与呈现，不换数字、不改等级、不加因果。跨版本抽查 3 个数字，指不回 meta = 未过关。

## 10. 交付前自检

- [ ] 每条实质断言有标签或锚点
- [ ] 跨仓引用带 `repo@rev`
- [ ] `[假设]` 没有被写成实测
- [ ] 没有未复核的「0 命中」
- [ ] 没有编造的链接 / 数字 / 日期
- [ ] 关键结论有四元组或等价的范围声明
